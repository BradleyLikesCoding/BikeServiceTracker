# BikeServiceTracker
    Our program is made for bikers in the need of service logs and reminders to service there bike the web interface is pretty simple to add a reminder for somthing you want to service you click setup service reminder and then fill in the boxes hit submit then close thats it for that when you get to enough miles in the middle of the page it will remind you to service what you set up once done you click add to log how you track your miles is you click add ride and then enter the number of miles and click submit it adds those up to know how far you rode.
